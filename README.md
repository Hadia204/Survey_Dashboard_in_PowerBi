 Data Professional Survey Breakdown | Power BI Dashboard

 Overview:
This interactive Power BI dashboard analyzes survey data from professionals in the data field to uncover key insights
regarding salaries, popular programming languages, job satisfaction, and demographic distributions.

 Key Metrics & Features:
1. Key Performance Indicators (KPIs):Highlights total survey respondents (630) and average age.
2. Salary Analysis: Bar chart visualizing average salary categorized by job roles (Data Scientist, Data Engineer,
3. Data Architect, Data Analyst, etc.).
4. Demographics: Treemap showing respondent distributions across major countries (United States, Canada, United Kingdom, India, and others).
5. Skill & Tool Preferences: Column chart tracking favorite programming languages (Python, R, JavaScript, C/C++, etc.).
6. Satisfaction Gauges: Visual rating scales measuring overall satisfaction with salary and work/life balance.

 Tools Used
1. Power BI Desktop
2. Power Query (Data Cleaning & Transformation)
3. DAX (Data Analysis Expressions)
